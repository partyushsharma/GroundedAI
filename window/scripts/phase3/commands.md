# Phase 3: Configurable Retrieval Pipeline & Ablation Framework

Phase 3 introduces a declarative, configuration-driven ablation framework to evaluate and benchmark different retrieval strategies (dense search, sparse BM25, hybrid fusion, query transformations, reranking, and diversity filtering) against the golden set dataset.

---

## 📁 File Breakdown (What and Why)

### 1. `scripts/phase3/config_loader.py`
- **What**: Contains the `RetrievalConfig` Pydantic data model and `load_config(path: Path)` parser function.
- **Why**: Validates experiment YAML configuration files and enforces strict typing and defaults across experiments.

### 2. `scripts/phase3/config/retrieval_pipeline.py`
- **What**: Implements the `RetrievalPipeline` class.
- **Why**: Encapsulates model initialization (e.g. `SentenceTransformer`), FAISS index loading, document metadata loading, and vector search querying.

### 3. `scripts/phase3/config/ablate.py`
- **What**: Main ablation experiment execution engine.
- **Why**: Reads configuration YAMLs, loads answerable queries from the golden set (`data/golden/golden_set_with_unanswerable.jsonl`), runs candidate retrieval, computes evaluation metrics (`Recall`, `Precision`, `NDCG`, `MRR`), and records the performance in CSV format.

### 4. `scripts/phase3/config/generate_results_table.py`
- **What**: Results formatting script.
- **Why**: Reads the generated CSV results, extracts key benchmark metrics (`recall@10`, `mrr`, `ndcg@10`), sorts experiments by Recall@10 descending, and exports a clean Markdown table.

### 5. `scripts/phase3/config/baseline.yaml`
- **What**: Baseline configuration file (`baseline_dense_flat`).
- **Why**: Defines baseline dense vector retrieval using FAISS exact Flat index and `BAAI/bge-base-en-v1.5` embeddings.

### 6. `scripts/phase3/config/hybrid_rrf.yaml`
- **What**: Hybrid search configuration file template.
- **Why**: Defines parameters for hybrid retrieval using Reciprocal Rank Fusion (RRF) combining dense and BM25 sparse search.

### 7. `scripts/phase3/commands.md`
- **What**: Phase 3 documentation file.
- **Why**: Guides users on commands, file responsibilities, and generated output artifacts.

---

## ⚙️ Commands to Run Phase 3

### 1. Run a Single Ablation Experiment
Executes an experiment using a specific YAML configuration file:
```bash
python scripts/phase3/config/ablate.py --config scripts/phase3/config/baseline.yaml
```
*Note: If using project virtual environment on Windows:*
```powershell
.venv\Scripts\python.exe scripts/phase3/config/ablate.py --config scripts/phase3/config/baseline.yaml
```

### 2. Run All Ablation Experiments
Executes all YAML experiment configurations in `scripts/phase3/config/`:
```bash
python scripts/phase3/config/ablate.py --all
```

### 3. Generate Summary Results Table
Formats experiment metrics into a Markdown table:
```bash
python scripts/phase3/config/generate_results_table.py
```
